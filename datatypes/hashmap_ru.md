# HashMap

Типизированная хэш-карта: поле (Payload) → значение (Variant). Атомарные операции над
отдельными полями выполняются на сервере. Аналог Redis hash, но со строгой типизацией
полей и значений.

Применение: профили пользователей, настройки сессии, объекты с полями, счётчики,
сгруппированные по сущности.

## Java API

| Метод | Что делает | Применение |
|---|---|---|
| `createMap(key, map, ttl?)` → `KeyHintData` | Создать карту с начальным содержимым | Инициализация профиля/настроек |
| `getMap(key)` → `Map<Payload, Variant>` | Прочитать всю карту | Полная выгрузка объекта |
| `getInContainer(key, field)` → `Variant` | Прочитать одно поле | Точечное чтение |
| `putAll(key, map)` → `Integer` | Записать/обновить набор полей | Пакетное обновление |
| `update(key, field, value)` → `Variant` | Обновить поле | Точечная запись |
| `containsKey(key, field)` → `Boolean` | Проверка существования поля | |
| `removeFromContainerByKey(key, field)` → `Integer` | Удалить поле | |
| `popInContainer(key, field)` → `Variant` | Атомарно прочитать и удалить поле | Одноразовые токены внутри объекта |
| `addInContainer(key, field, delta)` → `Number` | Атомарный инкремент поля (int64/double) | Счётчики по сущности без локов |
| `exchangeInContainer` / `subInContainer` / `andInContainer` / `orInContainer` / `xorInContainer` | Остальные атомики на полях | Битовые флаги и счётчики внутри объекта |
| `getSize(key)` → `Integer` | Количество полей | |

## Замечания

- Поля типизированы: поле-счётчик остаётся int64, а не строкой.
- TTL назначается на контейнер целиком.
- Для чтения больших карт есть стриминг (батчами) на уровне gRPC API.
